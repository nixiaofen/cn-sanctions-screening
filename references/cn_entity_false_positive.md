# 中文实体制裁筛查误命中（False Positive）判定规则库

> **定位**：本文档为制裁筛查流程中「中文实体名称比对」环节的辅助判定规范，用于降低自动匹配的误报率与漏报率。
> **适用对象**：法务、合规、贸易合规及 KYC/AML 岗位人员，以及为上述人员构建筛查工作流的工程师。
> **声明**：本文档提供的是**事实比对与风险线索归纳方法**，不构成法律意见或终局合规结论。是否阻断交易、是否申报，须由具备执业资格的专业人士结合具体事实与管辖独立判断。所涉清单与规则更新频繁，以各司法辖区官方最新公布文本为准。

---

## 一、为什么中文实体比对需要单独一套规则

主流开源筛查工具的设计前提是「名单页为英文」：其变体生成逻辑会将中文输入自动转为英文/拼音变体，并在多处以 `非中文字符` 为条件**显式跳过中文变体**再做匹配。

这在面向 OFAC SDN、BIS CSL 等英文库时是合理的；但一旦检索对象是中国官方公告（以中文发布、且常以「中文名（英文名）」并列形式列名），该前提即失效：

- 中文变体被丢弃，导致**漏报**（实体已在名单，却因未检索中文名而报「未命中」）；
- 英文名与中文公告中的英文并列名虽可部分对上，但**中文名本身才是公告的正式列名**，仅靠英文名不足以支撑结论；
- 中国管制清单以「公告/部令」形式逐次发布，**不存在统一的在线查询数据库**，匹配对象是自然语言文本而非结构化字段，误报率天然更高。

因此中文实体比对需要独立的判定规则，而非简单复用英文匹配逻辑。

---

## 二、中文实体名称的典型误报模式

### 2.1 高频字号撞名（最高频误报来源）

中文企业名称结构为「行政区划 + 字号 + 行业 + 组织形式」，其中字号仅 2–4 字，且大量使用高频通用词。

- **高风险字号**：国际贸易、实业、科技、进出口、投资、贸易、供应链、国际、环球、亚太
- **典型情形**：被列名实体为「XX 国际贸易有限公司」，而筛查对象为「YY 国际贸易有限公司」，自动匹配若仅按子串或编辑距离比对，极易误判。
- **判定规则**：字号必须完全一致；行业词与组织形式词**不计入**匹配依据；存在任一字符差异即视为不同主体，除非有额外证据支持同一性。

### 2.2 母子公司与关联公司混同

被列名的是「A 公司」，而筛查对象是其子公司、母公司、兄弟公司或更名后主体。

- **判定规则**：默认**不**将关联主体等同处理。中国清单的列名效力以公告列名主体为准；对关联主体的处理属独立的合规判断（如「50% 规则」在中国法下**并不当然适用**），不得由匹配程序自动得出。
- **操作要求**：程序判定为「关联但未列名」时，输出状态应为 `manual_review` 并标注关联路径，而非 `hit` 或 `clean`。

### 2.3 简体 / 繁体差异

港、澳、台及海外华商实体在公告中可能以繁体列名，筛查输入常为简体。

- **示例**：「台積電／台积电」「滙豐／汇丰」（「滙」与「汇」为异体，非标准简繁对应）。
- **判定规则**：匹配前应做简繁转换，并额外维护异体字映射表（如 滙/汇、峯/峰、羣/群）；异体字差异**不构成**排除命中的理由。

### 2.4 音译与译名分歧

同一外文名存在多种中文译法，且官方公告所用译名可能与媒体通行译名不同。

- **示例**：Skydio 中文列名为「斯凯迪奥公司」，而非音译「斯基迪奥」；Teledyne FLIR 列名为「特励达」系统，非「泰力丹」。
- **判定规则**：不得仅凭一种译法未命中即判定 CLEAN；应结合**英文并列名**交叉核验。官方公告通常在中文列名后附英文原名，该英文名是比中文名更稳定的匹配锚点。

### 2.5 注册名与品牌名不一致

实体以品牌名（含中文音译品牌）运营，注册名完全不同；或注册名包含品牌名但组织形式不同。

- **判定规则**：品牌名命中只可作为**线索**（状态 `manual_review`），不得直接判 `hit`；须回溯至注册主体全称方可确认。

### 2.6 中资离岸架构

注册于 BVI、开曼、新加坡、香港等地的中资背景实体，其注册中文名与实际运营主体、对外宣称名称常不一致，且同一集团内大量使用相近字号。

- **判定规则**：应将**注册地**作为独立字段记录；离岸注册主体与境内运营主体不得因名称相近而自动关联；涉及 UFLPA（维吾尔强迫劳动预防法）等涉产能穿透场景时，需额外核查股权与实际控制人，超出本规则库范围。

### 2.7 国家/地区代码与地名碰撞

「中国」「香港」「台湾」等词出现在实体名称中时，易被自动匹配误判为与清单中含同类词的条目相关。

- **判定规则**：纯地理/国别词不计入匹配依据；匹配锚点必须是字号或注册名核心部分。

## 三、误命中判定流程

```
输入实体名称（中文）
      │
      ▼
[1] 名称规范化：简繁转换 / 异体字归一 / 去除组织形式与行业词
      │
      ▼
[2] 字号提取与比对（核心锚点：字号，而非全称）
      │
      ├─ 字号完全一致 ──→ [3a] 核对注册地、组织形式、英文并列名 → 一致 → HIT
      │                                              └→ 不一致 → MANUAL_REVIEW
      ├─ 字号相近（编辑距离 ≤ 1 或音近）──→ MANUAL_REVIEW（标注疑点）
      └─ 字号不同 ──→ CLEAN（但仍需英文锚点二次核验）
      │
      ▼
[3] 英文并列名交叉核验（中国公告通常附英文名）
      │
      ▼
[4] 关联关系核查（母/子/兄弟公司）→ 仅标注，不自动等同
      │
      ▼
[5] 留痕：截图 + 公告文号 + 检索时间戳
```

### 状态定义

| 状态 | 含义 | 后续动作 |
|------|------|----------|
| `hit` | 名称核心锚点与公告列名一致，且注册地/组织形式吻合 | 进入合规评估流程 |
| `manual_review` | 名称相近、仅品牌名命中、存在关联关系，或证据不足以确认/排除 | 人工复核，不得自动放行 |
| `clean` | 核心锚点不同，且英文锚点亦未命中 | 记录留痕，按周期复筛 |
| `error` | 页面无法访问、栏目结构变更等程序性失败 | **不得视为 clean**，须人工补核 |

> **重要**：`error` 与 `manual_review` 均不得被下游流程当作「未命中」处理。中国清单公告页面存在访问节流与改版风险，程序性失败与「确认未列名」在合规后果上完全不同。

## 四、必须人工复核的情形清单

出现以下任一情形时，程序结果只能作为线索，不得作为终局依据：

1. 实体名称中含高频字号（见 2.1）；
2. 实体名称仅以品牌名或简称提供，无注册全称；
3. 存在已知或可查的母子公司、兄弟公司关系；
4. 实体注册地与实际经营地不一致，或属离岸架构；
5. 检索结果为 `manual_review`、`error`；
6. 公告页面结构近期发生变更（如栏目改版、列表分页调整）；
7. 实体名称含繁体、异体字或多种音译变体；
8. 涉及航空、无人机、半导体、监控设备等高敏感行业——该等领域名单更新频繁且列名密度高，建议提高复筛频率。

## 五、与英文清单的交叉核验建议

中国官方公告通常以「中文列名（English Name）」形式并列提供英文原名，这是比对中最稳定、最应优先使用的锚点。建议的核验顺序：

1. 以英文并列名比对 OFAC SDN、BIS CSL、EU、UK 等国际清单，确认是否存在「双向列名」情形；
2. 对同时列名于中外清单的实体，**特别注意中外措施的法律效果方向相反或不一致**的风险（如一方禁止交易、另一方要求交易），此类情形必须提交法律专业人士单独评估，不得由筛查工具自动得出处置建议；
3. 记录双向核验的检索时间戳，因清单动态调整，任何单次结果均有时效性。

---

## 六、留痕与可追溯要求

筛查记录至少应包含：

- 被查实体全称及所使用的全部名称变体；
- 检索时间（含时区）；
- 检索来源 URL 及公告文号；
- 页面截图（含命中位置高亮）；
- 程序判定状态与人工复核结论；
- 复核人及复核日期。

以上记录构成合规审计的基础工作底稿，也是证明筛查义务已履行的主要证据形式。
